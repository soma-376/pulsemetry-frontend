# 구현 계획

확정: 2026-09-09. 사용자 선택: 콘솔 전체 / 목업 우선·연동 준비 / 데스크톱·태블릿.

현재: **5단계 완료. 다음 회차는6단계(P4 시나리오 카탈로그·실행 흐름).**

## 목표와 기술
- 독립 로컬 Git 저장소 pulsemetry-frontend. React, TypeScript, Vite, npm.
- CSS Modules·CSS 변수, 접근성 primitives는 Radix UI.
- 1단계에 React Router·TanStack Query·MSW·OpenAPI 타입 생성 도입 완료. 차트 단계에 Recharts 도입.
- Vitest는1단계 도입 완료. React Testing Library는 컴포넌트 테스트 필요 시 추가. 브라우저 검증은 Playwright.
- 실제 백엔드 수정·실서비스 검증·배포는 범위 밖.
- 화면은 목업 데이터로 완성하고, 같은 계약의 실제 API로 교체할 수 있게 구현한다.

## API 인터페이스
- OpenAPI 원본에서 타입 생성. UI → 공통 HTTP 클라이언트 → MSW 또는 실제 API.
- 열 지향 DataFrame 변환 계층으로 timeseries/table/distribution/scalar를 해석한다.
- URL 전역 필터, 상대 시간 서버 해석, 위젯별 요청 및 뷰포트 지연 조회.
- 수동 새로고침 기본, 자동 최소 5분. 요청 취소·캐시 키에 필터를 반영한다.
- null/미관측/분모0/suppressed와 0 구분. 부분 실패는 위젯별 표현.
- 인증 토큰은 메모리 보관. 목업 모드 명시. 실제 API 실패 시 목업 대체 금지.
- 개인 식별 조회에 X-Audit-Reason, 역할과 팀 범위 반영. 서버 권한 검사를 UI가 대신한다고 가정하지 않는다.
- 시나리오 성공 시 반환 프레임으로 즉시 표시하고 중복 조회하지 않는다.
- 모호하거나 충돌하는 명세는 사실/가정으로 기록하고 목업 동작을 명시한다.
